# Modern Robotics и Physical AI

Бесплатный онлайн-курс о современной робототехнике: от классического управления и behavior cloning до VLA-моделей и гуманоидов. Каждый урок — самодостаточная HTML-страница с лабораторными работами: небольшие нейросети обучаются прямо в браузере, без сервера и без установки.

Сайт курса: [modernrobotics.ru](https://modernrobotics.ru). Автор — Олег Шипитько.

## Что внутри
```
site/        главная страница, 404 и config.json со ссылками и списком опубликованных уроков
  index.src.html, 404.src.html     исходники страниц (about.html — переадресация на блок «Об авторе»)
  build.py                         сборка: подставляет иконки и ссылки из config.json
  assets/                          стили, иконки, фото, интерактивы первого экрана (assets/hero)
lessons/     уроки курса
  build.py   сборка уроков в самодостаточные HTML-файлы в site/lessons/
  shared/    общие модули: канвас и подписи (kit.js), миссии лабораторий (missions.js), сортировка карточек (cards.js),
             кнопка «Сказать спасибо» (thanks.js),
             дом Ады и лаборатория «Ты — оператор», модель привода (actuator-core.js),
             двухзвенная рука (arm-core.js), планировщик со скользящим горизонтом (mpc-core.js)
  l01/       урок 0.1 «Две парадигмы: правила и данные»
  l02/       урок 0.2 «Устройство робота: приводы и сенсоры»
  l03/       урок 0.3 «Кинематика и управление»
  l04/       урок 0.4 «Оценка состояния и планирование»
  l11/       урок 1.1 «Behavior Cloning»
  l12/       урок 1.2 «DAgger и обучение с вмешательствами»
server/      thanks/ — счётчик «Сказать спасибо»: функция Yandex Cloud Functions и база YDB serverless
proto/       прототипы лабораторий, из которых выросли уроки
tools/       проверки в headless Chrome (без внешних зависимостей) и подбор параметров лаб в Node
```

## Сборка и проверка
Нужны Python 3 и Node.js 18+; для проверок — Google Chrome.
```
python3 site/build.py          # главная, 404, robots.txt и sitemap.xml
python3 lessons/build.py all   # уроки → site/lessons/
open site/index.html           # всё работает локально, без сервера
tools/deploy.sh --dryrun       # выкладка в Yandex Object Storage: что уйдёт на сайт

node tools/site_hero.js        # интерактивы первого экрана
node tools/lesson01.js         # урок 0.1
node tools/lesson02.js         # урок 0.2
node tools/lesson03.js         # урок 0.3
node tools/lesson04.js         # урок 0.4
node tools/lesson11.js         # урок 1.1
node tools/lesson12.js         # урок 1.2
```

## Как устроены уроки
- Лаборатории — миссии на живой сцене: у каждой цель с проверкой ✓/✗, ставка на исход, подсказка и разбор; ручки появляются по мере миссий, в конце — свободный режим.
- Модели в лабораториях настоящие и детерминированные: зерно случайности фиксировано, поэтому тексты объяснений совпадают с тем, что видит читатель.
- После правок движка лаборатории перепроверяй эффекты в Node: параметры подобраны так, чтобы опыты давали устойчивый результат.
- Цвета смыслов: классические методы — синий `#2a78d6`, нейросети — оранжевый `#eb6834`, гибриды — фиолетовый `#4a3aa7`.
- Факты и цифры сверяются с первоисточниками перед публикацией урока.

## Публикация
- Какие уроки опубликованы, задаёт `site/config.json` → `PUBLISHED`: по этому списку главная отмечает уроки «доступен», строится `sitemap.xml`, и только они попадают в выкладку.
- `tools/deploy.sh` собирает всё в `dist/` и синхронизирует с бакетом `modernrobotics.ru` через AWS CLI (профиль `mr`, endpoint `storage.yandexcloud.net`). Флаги: `--build-only`, `--dryrun`.
- Облако настраивается через `yc` скриптом `tools/cloud-setup.sh`: бакеты сайта и www, зона DNS, сертификат Let's Encrypt, HTTPS и ключ для выкладки (шаги `buckets`, `dns`, `cert`, `https`, `deploy-key`, `status`).
- Шрифты Inter и JetBrains Mono лежат на своём сервере: `site/assets/fonts/` (SIL Open Font License).
- Картинка превью ссылок `site/assets/og.png` рисуется скриптом `node tools/og_image.js`.
- Кнопка «Сказать спасибо» на главной и в конце уроков показывает общий счётчик. Его хранит функция в Yandex Cloud: `server/thanks/deploy.sh` создаёт базу YDB serverless, сервисный аккаунт и функцию и записывает её адрес в `config.json` → `THANKS_API`. В базе только число, о читателях ничего не хранится. Проверка логики без облака: `python3 server/thanks/test_index.py` (нужен пакет `ydb`).
